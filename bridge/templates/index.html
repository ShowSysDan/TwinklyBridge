Controllers

Each controller takes its LEDs from sACN (universe and start channel) or DDP (start byte), in chain order. Edit a number to repatch, or patch all of them at once.

sACN input

On a PC with several adapters, set the interface to the IP that faces the console. If Eos is on another VLAN, untick multicast and set its sACN output to unicast to this PC.

Export for Eos

Builds an Eos Pixel Map CSV from the maps above and the patch in the left column, so what the console sends is exactly what the bridge expects. 3D maps are flattened first. Import on the desk with File, Import, CSV, Pixel Maps.

Eos counts 512 addresses per universe; keep "channels per universe" at 510 so no pixel straddles a boundary. The patch sheet lists channel, absolute address, port/offset and DDP byte per LED, for Eos's patch import or for checking against the desk.
